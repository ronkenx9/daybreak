# Daybreak mobile mockup pack

**Builder plan:** [Daybreak mobile build plan](../MOBILE-BUILD-PLAN.md)

Visual direction: a playful, trustworthy stock-learning and community app. The interaction energy borrows from Duolingo's short guided loops, mascot reactions, progress paths, and celebrations while retaining Daybreak's own palette, plush characters, product language, and financial clarity.

## Boards

1. `01-onboarding.png` — welcome, interest selection, Base/Solana wallet connection.
2. `02-market-and-trade.png` — daily discovery path, stock detail, transaction review.
3. `03-events-passport-analytics.png` — corporate-action impact, instrument facts, portfolio analytics.
4. `04-circles-and-rewards.png` — circle discovery, community detail, transparent reward claim.
5. `05-learn-create-profile.png` — learning path, creator launch review, profile and mascot wardrobe.
6. `06-mascot-motion.png` — eight reusable mascot motion states and reduced-motion behavior.
7. `07-design-bible.png` — palette, type hierarchy, spacing, navigation, components, and mascot placement.

## Non-negotiable visual rules

- One primary task per screen.
- Use the five-tab mobile navigation: Home, Markets, Circles, Portfolio, You.
- Keep prices, source, market session, and freshness together.
- Separate company events, token treatment, and personal-position impact.
- Put issuer rights and restrictions in the instrument passport, not in dense legal copy.
- Use the mascot as a guide or reaction. It never covers prices, terms, warnings, or primary actions.
- Rewards feel communal and transparent, never casino-like.
- Reduced motion uses a 160ms crossfade and expression swap.
- Generated copy and numerical examples are illustrative UI content; production values must come from verified data.
