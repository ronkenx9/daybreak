# Gates: Daybreak mobile mockup pack

OWNS: docs/mobile-mockups/**

Scope: Produce a coherent, builder-ready visual mockup set covering Daybreak's primary mobile product flows and mascot motion states.

- [x] G1: The visual set covers onboarding, discovery, stock detail, corporate actions, compliance, analytics, circles, creation, rewards, and profile/navigation.
  EVIDENCE: Seven 1536x1024 boards cover 15 numbered mobile screens plus the design and motion systems; README maps the full product flow.

- [x] G2: Every screen uses one consistent Daybreak mobile design system with readable type, safe areas, coherent navigation, and existing mascot identity.
  EVIDENCE: Visual review confirms the same electric-blue/porcelain/ink palette, black device frame, rounded type, five-tab navigation, cloud surfaces, and supplied plush character model across all five screen boards.

- [x] G3: Mascot behavior is shown as a reusable state system including idle, guide, success, warning, loading, and celebration moments.
  EVIDENCE: `06-mascot-motion.png` contains eight labeled states with timings, keyframe direction, motion character, and reduced-motion behavior.

- [x] G4: Generated mockups are visually inspected and weak or inconsistent renders are regenerated before handoff.
  EVIDENCE: All boards were inspected at generation time; the first motion sheet was rejected for crowded card-8 text and regenerated as the clean final `06-mascot-motion.png`.
